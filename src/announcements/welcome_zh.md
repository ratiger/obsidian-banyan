# 🌲 欢迎使用 Banyan

Banyan 通过卡片视图直观查看笔记内容，用标签来组织笔记，通过以标签为主的筛选方案来检索笔记。

## 🚀 Banyan 使用指南

### 📌 核心理念

传统文件树：你需要记住笔记存放在哪个文件夹里，如`社科/心理/阿德勒/被讨厌的勇气.md`。   
 
Banyan：笔记的位置不再重要，卡片面板按时间顺序展示笔记，你只需通过 标签、日期、关键词 即可快速定位目标笔记。  
创建笔记时，你关注的不是“放哪里”，而是“属于什么”，如，`#社科/心理/阿德勒 #阅读 #进展/进行中`，之后你便可以不同的方式查看到该笔记。  

### ⚡ 快速上手

1. 笔记目录  
插件只管理`笔记目录`下的文件，默认为`cards`。你可以在设置中改为仓库下的任意目录。  


2. 创建第一篇笔记  
- 新建笔记标题默认使用当前时间，也可随意修改。  
- 添加笔记编辑区中的标签会写入笔记到属性`tags`中。  
- 插件会同时识别笔记`tags`属性和笔记正文中的标签，两者一起用来筛选。  


3. 用标签筛选  
- 支持标签“或、且、非”组合筛选，例如你可以筛选出 `#项目/A`或`#项目/B`中`#进展/进行中`的**不**`#紧急`的笔记。 
- 此外还支持 日期范围 和 关键词 三者一起筛选。

4. 进阶设置
- 自定义存放目录：新建笔记默认按`年/季度/月/日`层级存放，但**层级不影响使用**，不过你也可以在设置中自定义路径。
- 配置目录说明：`笔记目录`根目录下会自动生成 `banyan_config` 文件夹，用于存储插件配置文件，它目前无法隐藏，否则其中的 Markdown 文件无法正常读取。

### 💡 现在就试试
新建一篇笔记，打上 `#进展/待办` 标签，在卡片面板侧边栏中创建含`#进展/待办`标签的筛选方案，然后点击该筛选方案查看效果吧！
