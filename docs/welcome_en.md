# 🌲 Welcome to Banyan

Banyan provides a new way for you to organize and view notes:  
- **More Intuitive Note Browsing**: Compared to viewing just note titles, the card view lets you browse notes more intuitively;  
- **Organize Notes with Tags**: Traditional tree structures only allow a single classification method. Organizing notes with tags allows you to organize notes in multiple ways.

## ⚡ Quick Start

> The plugin only manages `markdown` files under the `Notes Directory` specified in settings (defaults to `cards`, but can be changed to any directory).  
> *All notes mentioned below are assumed to be inside this directory, represented by `~/`* 

### Creating Notes  
You can create notes in specific locations as usual, such as `~/Sciences/Psychology/TheCourage.md`. You will see this note in the card panel.  
However, if you don't care about the location of your notes, you can use the plugin's note creation feature, which creates notes with default locations and titles.  
The highlight of this plugin is organizing notes using tags. Tags in both the note body and properties are displayed in the card view and participate in search.

### Searching Notes & Filter Schemes  
In addition to basic keyword search, date range and tag searches are also supported. Flexible tag search schemes can be combined using "OR, AND, NOT" logic.  
Frequently used searches can be added to "Saved Filters".

### Random Browsing  
You can randomly browse all notes or notes within a specific filter scheme to unexpectedly encounter your past notes.

### 💡 Try It Now

- Create a new note and add the `#Progress/Todo` tag  
- Create a filter scheme containing the `#Progress/Todo` tag in the Card Panel sidebar  
- Click on that filter scheme to see the results

## 🤖 Additional Information

- **Storage Location for New Notes**: New notes are stored in a `Year/Quarter/Month/Day` hierarchy by default, but **the hierarchy does not affect usage**. You can also customize the path in the settings.
- **Configuration Directory**: A `banyan_config` folder is automatically generated at the root of the `Notes Directory` to store plugin configuration files. It currently cannot be hidden, otherwise the Markdown files inside cannot be read properly.
