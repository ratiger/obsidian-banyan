# 🌲 欢迎使用 Banyan

Banyan 为你提供一种新的组织和查看笔记的方式：  
- 更直观查看笔记：相较于仅看笔记标题，笔记的卡片视图让你更直观地查看笔记；  
- 用标签来组织笔记：传统地树状方式只能让你以某一种分类方式来组织，通过标签来组织笔记可以让你以多种分类方式来组织笔记。

## ⚡ 快速上手

> 插件只管理设置中`笔记目录`下的`markdown`文件，默认为`cards`，也可改为任意目录。  
> *以下提及的笔记均默认在该目录之内，用`~/`代替* 

### 创建笔记  
你可以照旧创建特定位置的笔记，如`~/社科/心理/被讨厌的勇气.md`。在卡片面板中可以看到该笔记。  
但如果你不关心笔记的位置，可使用本插件的创建笔记功能，它创建的笔记会有默认的位置和标题。  
本插件的特色是以标签的方式组织笔记，在笔记正文或属性中的标签均会显示在卡片视图，并参与检索。

### 搜索笔记 与 过滤方案  
除了基本的「关键字」搜索，还支持「日期范围」和「标签」搜索，通过 “或、且、非” 的方式可以组合出灵活的标签搜索方案。   
对于常用的搜索，可以添加为「常用过滤」。

### 乱序浏览  
你可以对所有笔记或特定筛选方案内的笔记进行乱序浏览，以与旧笔记不期而遇。

### 💡 现在就试试

- 新建一篇笔记，打上 `#进展/待办` 标签  
- 在 卡片面板 侧边栏 中创建含`#进展/待办`标签的筛选方案  
- 点击该筛选方案查看效果

## 🤖 更多说明

- 新建笔记存放位置：新建笔记默认按`年/季度/月/日`层级存放，但**层级不影响使用**，不过你也可以在设置中自定义路径。
- 配置目录说明：`笔记目录`根目录下会自动生成 `banyan_config` 文件夹，用于存储插件配置文件，它目前无法隐藏，否则其中的 Markdown 文件无法正常读取。
